- CV link (`public/cv.pdf`)

## Run locally

Requirements: Node.js 20 or later and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Check before publishing

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import that repository at https://vercel.com/new.
3. Keep the framework preset as Next.js and the project root as the repository root.
4. Deploy and test the generated public URL.

The current project uses static export configuration in `next.config.ts`; Vercel can host the exported site. Revisit that configuration if server-side features are added later.
